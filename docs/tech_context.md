# Technology Context

## Stack, Frameworks, Tools

### Backend

- **Language**: Java 25 LTS
- **Framework**: Spring Boot 3.5.6
- **Build Tool**: Maven 3.9+
- **HTTP Client**: RestClient (Spring 6)
- **Testing**: JUnit 5, Mockito (optional for units)

### Frontend

- **Markup**: HTML5
- **Scripting**: JavaScript ES2024
- **Color Detection**: Color Thief 2.4.0
- **Styling**: CSS3 with Grid/Flexbox
- **Testing**: Playwright for integration tests

### Development Tools

- IDE: VS Code with Copilot
- Version Control: Git
- CI: None (demo only)
